Sticky Module Demo

This page demonstrates a sticky table of contents that stays visible while the article content scrolls.

Introduction

Sticky positioning is useful when an element should behave normally until it reaches a specific offset. After that point, it stays fixed relative to the scroll container.

This page is intentionally long so the table of contents has enough room to demonstrate sticky behavior while the reader scrolls.

Layout Behavior

The sidebar and article are arranged in a two-column grid on larger screens. The sidebar contains a sticky module that remains visible as the article continues scrolling.

On smaller screens, the layout stacks into one column so the content remains readable without forcing a narrow sidebar.

Overflow Bug

Sticky positioning can stop working when an ancestor creates a new scrolling context with overflow hidden, overflow auto, or overflow scroll. That makes the sticky element stick relative to the wrong container or fail to stick at all.

The fix is to avoid placing overflow on the ancestor that sits between the sticky element and the page scroll container.

Sticky Fix

In this demo, the decorative clipping effect is moved to a pseudo-element instead of applying overflow hidden to the layout wrapper. That keeps the visual polish without breaking the sticky positioning.

This approach keeps the sticky module connected to the page scroll while still allowing the layout to have a designed container shape.
