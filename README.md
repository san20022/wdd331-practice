# Front-End Portfolio – WDD 331R Practice Site

This repository contains my final portfolio for **WDD 331R – Advanced CSS** at **BYU–Idaho**. Throughout the course I explored modern CSS techniques, responsive layouts, accessibility, design systems, and performance best practices while building a collection of practical projects.

The site serves as both a portfolio and a record of the concepts learned during the course.

## Features

- Responsive layouts using CSS Grid and Flexbox
- Design tokens with CSS Custom Properties
- Layered CSS architecture
- Fluid typography using a modular scale
- Light and dark theme support
- Responsive card layouts
- CSS Subgrid and Container Queries
- Sticky positioning demonstrations
- Professional resume page with print stylesheet
- Accessible contact form
- SVG icon system using inline sprites
- Motion with reduced-motion support
- Mobile-friendly navigation
- GitHub Pages deployment

## Running the Project

### Clone the repository

```bash
git clone <repository-url>
```

### Install dependencies

```bash
npm install
```

### Build the project

```bash
npm run build
```

### Run locally

Open the project using **Live Server** or any local development server.

## Accessibility

Accessibility was considered throughout the project by including:

- Semantic HTML structure
- Keyboard-friendly navigation
- Visible focus indicators
- Responsive layouts
- Accessible contact form
- Print-friendly resume
- Dark mode support
- SVG icons with appropriate accessibility attributes
